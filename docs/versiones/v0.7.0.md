## Qué descargar

| Fichero | Sistema | Edición |
|---------|---------|---------|
| `GodRemote-windows-x64.zip` | Windows de 64 bits | Completa (con RDP integrado) |
| `GodRemote-ssh-reforzado-windows-x64.zip` | Windows de 64 bits | SSH reforzada |
| `GodRemote-linux-x64.tar.gz` | Linux x86-64 | Completa |
| `GodRemote-ssh-reforzado-linux-x64.tar.gz` | Linux x86-64 | SSH reforzada |
| `GodRemote-macos-arm64.tar.gz` | macOS (Apple Silicon) | Completa |
| `GodRemote-ssh-reforzado-macos-arm64.tar.gz` | macOS (Apple Silicon) | SSH reforzada |

Cada paquete trae un único ejecutable y el manual (`LEEME.md`). La edición
«SSH reforzada» usa la versión más reciente de la librería SSH a cambio de
no llevar el cliente RDP integrado; las dos comparten configuración.

Los ejecutables no están firmados, así que Windows y macOS avisan la
primera vez que se abren. En Linux hacen falta las librerías de escritorio
habituales (véase el manual).

En Windows y macOS esta versión pasa sus pruebas automáticas, pero la
interfaz solo se ha manejado a mano en Linux.

## Novedades de la 0.7.0

- **Servidor X propio** con RENDER, SHAPE y RANDR: funcionan aplicaciones
  GTK 3, Qt 5, Tk, Motif y Java (Swing) además de las clásicas, y las
  ventanas se maximizan y se redimensionan por cualquier borde. GTK 4 y lo
  que necesite OpenGL siguen sin funcionar.
- **Paleta de órdenes** (`Ctrl+Mayús+P`) y atajos para cambiar, abrir y
  cerrar pestañas.
- **Protecciones**: confirmación al pegar varias líneas y al cerrar
  pestañas con sesiones vivas; color de pestaña por carpeta o equipo.
- **Automatización**: órdenes al conectar por equipo, y ejecutar una orden
  o un snippet en todos los equipos de una carpeta recogiendo la salida.
- **Baúl**: bloqueo automático por inactividad y visor de lo guardado.
- **SSH**: reenvío del agente y conexión a través de proxy HTTP o SOCKS5.
- **SFTP**: soltar ficheros desde el sistema, permisos, reanudar
  transferencias y sincronizar carpetas.
- **Terminal local** con la shell que se elija (PowerShell, cmd, WSL, Git
  Bash, bash, zsh…). Corregido: en Windows el terminal local se quedaba en
  blanco al arrancar.
- Compilación y pruebas automáticas en Windows, Linux y macOS.
