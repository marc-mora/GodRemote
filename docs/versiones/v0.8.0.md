## Qué descargar

| Sistema | Edición completa (con RDP integrado) | Edición SSH reforzada |
|---------|--------------------------------------|-----------------------|
| Windows de 64 bits, instalador | `GodRemote-windows-x64-instalador.exe` | `GodRemote-ssh-reforzado-windows-x64-instalador.exe` |
| Windows de 64 bits, portátil | `GodRemote-windows-x64.zip` | `GodRemote-ssh-reforzado-windows-x64.zip` |
| macOS (Intel y Apple Silicon), aplicación | `GodRemote-macos-universal.dmg` | `GodRemote-ssh-reforzado-macos-universal.dmg` |
| macOS, solo el ejecutable | `GodRemote-macos-universal.tar.gz` | `GodRemote-ssh-reforzado-macos-universal.tar.gz` |
| Linux x86-64, Debian/Ubuntu | `GodRemote_0.8.0_amd64.deb` | `GodRemote-ssh-reforzado_0.8.0_amd64.deb` |
| Linux x86-64, cualquier distribución | `GodRemote-linux-x64.tar.gz` | `GodRemote-ssh-reforzado-linux-x64.tar.gz` |

`SHA256SUMS.txt` trae la suma de cada fichero. La edición «SSH reforzada» usa
la versión más reciente de la librería SSH a cambio de no llevar el cliente RDP
integrado ni el aviso de versión nueva; las dos comparten configuración.

Los ejecutables **no están firmados**: Windows (SmartScreen) y macOS
(Gatekeeper) avisan la primera vez que se abren. En Linux hacen falta las
librerías de escritorio habituales (el `.deb` las pide solo).

Cada ejecutable publicado se ha abierto en su sistema antes de empaquetarlo
(se comprueba que pinta su ventana), pero la interfaz solo se ha manejado a
mano en Linux.

## Novedades de la 0.8.0

- **Windows sin tarjeta gráfica**: la ventana se pinta con DirectX 12, que
  funciona también en máquinas virtuales, servidores y sesiones de escritorio
  remoto donde antes la aplicación no llegaba a abrirse.
- **Paquetes**: instalador para Windows, aplicación universal en `.dmg` para
  macOS, `.deb` para Linux, icono propio y sumas SHA-256.
- **Aviso de versión nueva** en la barra de estado (una consulta a github.com
  al día como mucho; se puede desactivar).
- **Más formas de autenticarse por SSH**: certificados OpenSSH, códigos TOTP
  guardados en el baúl y rellenados al conectar, Pageant en Windows y llaves de
  seguridad FIDO2 a través del agente.
- **Disparadores** en los terminales (avisar o contestar cuando aparece un
  texto) y aviso cuando termina una orden larga en una pestaña de fondo.
- **Grabar y reproducir sesiones** en formato asciicast, e **historial de
  órdenes** por equipo con buscador.
- **Panel de estado** de una carpeta: todos sus equipos a la vez (conexión,
  latencia, CPU, memoria, disco, tendencia) con alertas por umbrales.
- **Servidor X**: funcionan las aplicaciones GTK 4, se dibuja el puntero que
  pide cada aplicación, las ventanas se minimizan y, de forma experimental,
  cada aplicación puede salir en su propia ventana del sistema.
